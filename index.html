About me

I am an AI/ML engineer and a PhD candidate in Electrical and Computer Engineering at the University of Toronto.

Right now I am an intern engineer at Huawei Technologies Canada, on the openJiuwen agent platform. I build tools for AI agents: a tester that finds failures in agent workflows and repairs them, tools that let an agent control a desktop safely, and plugins for the WorkSwarm client.

Before the PhD I was a data scientist at HARA AI in Tehran. I built the Persian language understanding service for an automated call center there and took it to production.

My PhD research is on reconfigurable intelligent surfaces for wireless sensing. I work on how to configure a surface so that a scene is easier to estimate, how to keep a radar target visible when other radars interfere, and when surface control can mislead a radar. I have published four IEEE conference papers on this, and a fifth was accepted at IEEE ISAC 2026.

I have also been teaching for several years. I started as a teaching assistant in the second year of my undergrad, and since 2024 I have been a course instructor at the University of Toronto.

WorkSwarm Eye and Voice

macOS plugin · Huawei internship · 2026

Look at a window and say what you want. The agent takes that window as its context and does the task.

WorkSwarm is the desktop client of the openJiuwen agent platform. My plugin follows your gaze with the Mac's webcam and outlines the window you are looking at. When you say "WorkSwarm" and your request, the agent receives the request together with a screenshot of exactly that window. Gaze tracking and speech recognition both run on the Mac.

I published it on the openJiuwen Agentic Hub. It has about 880 automated tests, and its companion app is checked with a signature and a checksum before it runs.

Workflow testing and repair

openJiuwen · Huawei internship · 2026

A system that tests LLM agent workflows, finds where they go wrong, and gets the faulty code steps repaired. It is about 30,000 lines of Python with more than 700 automated tests.

Testing
It checks a workflow against its plain-language specification without an answer key. Reference workflows built independently from the specification have to agree with each other, and when its checks cannot decide, it asks the workflow owner.
Repair
Each confirmed failure becomes a repair task for openJiuwen's program optimizer. A fix is accepted only after the original and the repaired workflows are run again on every input the tester used. I packaged the loop as a WorkSwarm plugin and ran it end to end inside WorkSwarm.

Python / openJiuwen / WorkSwarm plugin / Evaluation

Desktop control for agents

agent-core · WorkSwarm · Huawei internship · 2026

Two tools for agents that operate a computer. One limits what the agent can touch on your Mac. The other gives the agent a desktop of its own.

On your Mac
A tool for agent-core that lets an agent operate only the macOS windows you have shared, with focus guards, cancellation and bounded batches of actions. I opened it upstream as a pull request with more than 1,200 passing tests and about 88% statement coverage.
Its own desktop
I am now building a Linux desktop that runs in a container. The agent reaches it through an MCP bridge that checks a token on every call, so it works there and not on your machine. In every end-to-end run with a real model, the agent built the requested chart in its own desktop, left the original files unchanged and removed the desktop afterwards. The build passes its compatibility checks on both arm64 and x86_64.

Python / macOS / MCP / Docker / Regression testing

Research

My PhD is on reconfigurable intelligent surfaces (RIS) for wireless sensing. A RIS is a panel of small elements, and the reflection of each element can be set electronically. I work on three problems.

Open the research page

Configuring the surface to sense a scene

A surface with 16 elements and 4 states per element has 416 possible configurations, and only a few can be used in one sensing task. I search for the ones that make the scene easiest to estimate, with a Swendsen-Wang evolutionary method that needs no training.

In a synthetic study, 97.24% of 8,000 held-out cells were labelled correctly as empty, cube or sphere.

Read more

Keeping the target when other radars interfere

Another car's radar on the same channel can hide a weak target. I choose one setting of the surface loads that keeps the target and suppresses the interference, and I take into account that neighbouring elements of a real surface affect each other.

In simulation, the worst-case SINR is 13.33 dB higher than a design that ignores this coupling, at the reference operating point.

Read more

When a surface can mislead a radar

The same control can be used against a radar. I study a vehicle that carries a surface and makes a radar report a target at a wrong bearing and velocity, and how the result depends on the type of receiver.

The conference paper on this was accepted at IEEE ISAC 2026.
